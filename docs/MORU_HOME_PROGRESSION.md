# 모루 — 집의 성장과 마음의 행복

상태: 추가 기획. 아직 서비스에 적용하지 않았으며, 비용과 레벨은 초기 조정안이다.

## 중심 경험

동굴에서 시작해 방문과 마음기록을 쌓으며 더 편안한 집으로 이사한다. 집이 커져도 모루의 평소 처진 눈과 조용한 성격은 유지된다. 사용자가 쓰다듬고 마음을 나누면 눈빛이 밝아지고 웃는다.

메시지: **안전한 집은 삶을 편안하게 해주고, 소중한 관계와 내가 중요하게 여기는 것을 돌보는 시간은 마음을 채운다.**

주거 불안을 단순한 마음가짐 문제로 설명하지 않는다. 좋은 집의 안락함은 실제로 늘어나지만 집값이 행복도나 사람의 가치를 결정하지 않는다. 실제 주거 형태의 우열 대신 모루가 거쳐 온 장소의 이야기로 표현한다.

## 재화와 경험치

| 항목 | 획득 | 사용 |
|---|---|---|
| 마음밥 | 마음기록 단계마다 1개, 하루 최대 5개 | 기존 하루 최대 세 끼 자동 식사 |
| 방문포인트 | 한국 시간 하루 첫 접속 +10 P | 공간 구매 |
| 추가 방문포인트 | 마음기록 단계마다 +4 P, 하루 최대 +20 P | 공간 구매 |
| 경험치 | 기존 기록 단계 +4, 식사 한 끼 +2 | 공간 구매의 레벨 조건 |

하루 첫 방문과 다섯 단계 기록을 마치면 총 30 P를 모은다. 마음밥과 방문포인트는 별도 잔고다. 방문은 로그인 계정의 홈 조회 성공 시 인정하며, 게스트는 적립하지 않는다.

새로고침·여러 기기·기록 수정/삭제/재작성으로 중복 지급하지 않는다. 연속 출석 보너스, 벌금, 포인트 만료, 유지비, 먹이와 포인트 교환은 넣지 않는다. 구매 시 포인트만 차감하고 경험치·레벨·마음밥은 유지한다.

## 공간 성장 순서

사용자가 제시한 순서를 유지한다. 옥탑방과 반지하를 실제 부동산 가치의 순위로 설명하지 않는다.

|---|---:|---:|---|
| 동굴 | 1 | 무료 | 입구 밖 비, 안쪽의 마른 둥지와 담요 |
| 판자집 | 3 | 60 P | 창밖 빗줄기, 작은 등불과 낮은 침대 |
| 낡은집 | 5 | 150 P | 바랜 창틀과 눈 내리는 골목, 기운 이불 |
| 옥탑방 | 8 | 270 P | 비 오는 옥상과 도시 불빛, 창가 침대 |
| 반지하 | 12 | 450 P | 높은 창 너머 비 오는 길, 마른 실내와 간접조명 |
| 일반집 | 18 | 750 P | 넓어진 창과 수납장, 도시에 내리는 눈 |
| 가정집 | 25 | 1,200 P | 작은 식탁과 추억 사진, 생활감 있는 침실 |

총 구매 비용은 7,380 P. 하루 30 P를 모으고 다른 지출이 없다면 포인트만 기준으로 최소 246일이다. 실제 도달 시점은 레벨과 방문 빈도에 따라 달라진다. 현재 코드의 Lv.10/720 XP 상한을 확장하고 경험치 곡선을 검증해야 하므로, 이 표의 레벨을 현재 곡선에 그대로 적용하지 않는다.

초기에는 집과 기본 비·눈 풍경을 묶어서 판매한다. 날씨 변형의 별도 판매는 이후 확장한다. 구매한 공간은 언제든 무료로 다시 선택할 수 있다. 현재 집과 최고 해금 단계는 별도 저장한다.

## 구매 흐름

1. ‘이사하기’ 또는 포인트 잔고를 누른다.
2. 현재 공간과 다음 공간을 큰 미리보기 카드로 보여준다. 필요 레벨·잔고·가격만 표시한다.
3. 조건 충족 시 ‘구매하고 이사’, 미충족 시 ‘Lv.8 필요’ 또는 ‘120 P 부족’을 표시한다.
4. 사용자의 구매 버튼 클릭으로만 포인트를 차감한다. 자동 구매·자동 이사는 없다.
5. 새 방에 모루가 자리 잡는다. 집 구입만으로 행복도를 높이거나 웃는 표정을 재생하지 않는다.
6. 소유한 공간은 ‘머물기’로 무료 재선택한다.

## 행복도와 교감

| 상황 | 행복도 표시 | 반응 |
|---|---|---|
| 평소 | 고요함 | 처진 눈으로 쉬거나 잠든다. 울거나 고통스러워하지 않는다. |
| 쓰다듬기 | 반가움 | 눈웃음과 잠깐의 눈빛 반짝임, 가까이 기대기 |
| 마음기록 저장 | 포근함 | 작은 식사와 따뜻한 반응. 슬픈 기록도 동일하게 반긴다. |
| 중요한 가치 돌아보기 | 포근함 | 함께 고른 물건을 바라보거나 곁에 눕기 |
| 상호작용 종료 | 고요함 | 원래 조용한 표정으로 자연스럽게 복귀 |
| 며칠 뒤 돌아와 교감 | 반가움 | 원망 없이 맞이하기. 집·레벨·포인트 손실 없음 |

현재의 페이지 로드 직후 자동 눈웃음은 변경한다. 실제 클릭·터치·기록 저장이 눈빛을 밝히는 계기가 된다. 반복 교감으로 재화나 경험치를 무한 획득하지 않는다. 반응 종료를 행복 감점이나 사용자의 돌봄 실패로 표현하지 않는다.

## 내가 중요하게 여기는 것

기존 다섯 단계 기록과 하루 최대 보상은 유지한다. 기록 후 선택적으로 ‘오늘 지키고 싶었던 것’을 고른다: 관계, 쉼, 건강, 자율, 성장, 창작, 안정, 직접 적기. 선택은 언제든 바꿀 수 있다.

‘충족했어 / 조금 / 아직 / 모르겠어’로 돌아볼 수 있으나 어느 응답에도 보상 차등이나 감점은 없다. 가치 기록은 공간 구매 조건이 아니며 건너뛸 수 있다. 나중에 추억 상자에서 마음이 채워졌던 날을 직접 돌아보는 재료로 사용한다. 관계뿐 아니라 사용자가 중요하게 여기는 휴식·자율·건강 등의 가치도 존중한다.

## 첫 구현 범위

1. 기본 집을 동굴로 변경한다. 기존 침실 자산은 이후 공간에 재사용한다.
2. 행복도·방문포인트·이사하기를 홈에 추가한다.
3. 첫 방문과 기록 포인트를 서버에서 중복 없이 지급한다.
4. 동굴·판자집·낡은집부터 구매/선택을 제공한다. 나머지는 예정 공간으로 표시하고 구매를 막는다.
5. 성장 속도와 레벨 곡선을 검증한 뒤 후반 공간을 추가한다.

데이터 제안: 펫에 `visit_points`, `home_id`, `highest_home_tier` 추가. `pet_point_ledger`, `pet_owned_homes`에 지급·구매 이력 저장. 날짜별 방문과 기록 단계 보상에 고유 제약을 둔다. 구매 시 계정 행 잠금, 레벨/잔고 재검사, 포인트 차감, 소유권 부여, 현재 집 변경을 한 트랜잭션으로 처리한다. 같은 공간의 반복 구매는 다시 차감하지 않는다.

행복도는 우선 클라이언트의 짧은 반응 상태로 구현한다. 누적 친밀도와 혼용하지 않는다. 계정 삭제 시 가치 기록과 재화 이력도 기존 정책에 맞춰 삭제한다.

검증 항목: 날짜 경계, 동시 접속 중복 적립, 기록 삭제 후 재지급 방지, 이중 구매, 잔고 부족, 잠긴 공간 접근, 이전 집 무료 재선택, 미접속 불이익 없음, 동작 줄이기 설정.

## 구현 상태 업데이트

첫 구현 범위의 동굴·판자집·낡은집, 방문포인트 적립/구매/재선택 API, 행복도 상태 표시와 상점을 코드에 반영했다. 뒤의 여섯 공간과 Lv.50 확장은 아직 준비 단계다. 기존 Lv.10 상한을 유지한다. V40 마이그레이션(moru_homes)은 백엔드 재시작 시 적용된다. 실제 호스팅 DB 저장 검증은 아직 완료하지 않았다.

미로그인 상태는 닫힌 창문과 ‘나를 찾아줘’ 로그인 링크로 변경했다. 로그인한 사용자의 프로필 이름 또는 계정 닉네임으로 교감 메시지를 표시한다.

## 공간의 새 방향 (2026-11-12 적용)

공간은 더 이상 "허름한 곳에서 좋은 집으로" 올라가는 사다리가 아니다. **모든 공간이 틀어박혀 쉴 수 있는 아늑한 곳**이고, 이사는 더 나은 집이 아니라 다른 아늑함을 고르는 일이다.
조금 비현실적이어도 좋다: 첫 공간은 달리는 기차의 침대칸이라 창밖 풍경이 지나가고, 모루는 창가 침대에 앉아 쉰다.

|---:|---|---|---|
| 0 | 동굴 | 기차 침대칸 | 나무 벽, 둥근 모서리 창과 커튼, 줄 전구, 접이식 탁자의 등과 찻잔, 창가 침대와 담요. 창밖이 지나간다 |
| 1 | 판자집 | 다락방 | 기울어진 지붕 아래 둥근 창, 바닥에 깐 요와 누빔 이불, 쿠션 둘, 책 위의 등, 찻쟁반 |
| 2 | 낡은집 | 창가 침대방 | 천장까지 닿는 큰 창 옆에 붙인 침대, 창턱의 책과 촛불, 벽의 액자, 흰 이불 |

- 이름은 서버(`PetHomes`)와 화면(`HOME_NAMES`) 양쪽에 있다. 화면이 자기 이름을 먼저 쓰므로, 서버가 옛 이름을 주는 동안에도 그림과 이름이 맞는다.
