# 기존 바다와 분홍빛 노을·모바일 잉걸불

요청에 따라 소금평원과 수면 캐릭터 반사를 제거하고 기존 파도 바다로 복구했습니다. 백사장과 분홍빛 노을은 유지합니다.

## 시간에 따른 풍경

- 17:30부터 하늘이 서서히 물들고, 18:00~19:00에는 위쪽 하늘까지 붉은 분홍빛이 퍼집니다.
- 19:00 이후에는 보랏빛 잔광으로 어두워지고 20:18에는 밤 색으로 이어집니다.
- 22:00 이후에는 어두운 해변과 별·달·은은한 은하수가 있는 밤하늘로 이어집니다.

## Tripo 장작·잉걸불

새 `잉걸불.glb` 대신 바로 전 `campfire 3d model.glb`로 장작과 잉걸불을 되돌렸습니다. 원본 약 70.29MB·1,884,523삼각형에서 약 0.95MB·28,264삼각형으로 줄였습니다. 배포 자산은 `frontend/public/beach/models/tripo-firewood-mobile-v2.glb`이며 변환·검증 정보는 같은 폴더의 JSON에 있습니다. 원본 파일은 변경하지 않았습니다.

기하 구조에는 Meshopt 압축, 기본색에는 1024px WebP, 노멀·재질에는 512px WebP를 적용했습니다. `GLTFLoader.setMeshoptDecoder(MeshoptDecoder)`로 Three.js에 포함된 디코더를 연결합니다. 압축 파일을 다시 읽어 정상 인덱스·속성·노멀을 확인했으며 원본 경계 오차는 폭 대비 약 0.08%입니다. 경계 오차는 전체 시각 품질을 보장하는 수치가 아니므로 실제 화면의 작은 나뭇결은 별도로 확인해야 합니다.

기존 움직이는 불꽃·가루 색·장작을 모두 넣었을 때의 불 높이는 유지합니다. 장작이 소진되면 모델의 탄 나무와 주황 잉걸불이 남습니다. 모델을 읽을 수 없으면 기존 장작을 표시하고, 퇴장 중 로드가 끝나도 자원을 정리합니다.

모닥불 테두리 안의 단색 고동색 바닥에는 기존 `sand.jpg` 흙 이미지와 `sand-normal.jpg` 표면 요철을 연결했습니다. 장작 주변에서 실제 흙 알갱이 질감이 보이며 그림자를 받습니다.

## 서버와 확인

서버의 바다 쪽 이동 경계도 기존 z=-1로 복구했습니다. 이번 잉걸불 교체와 노을 표현은 프런트엔드 변경입니다. 커밋·푸시·운영 배포는 수행하지 않았습니다.

검사에는 연료 변화와 가루 효과, 모델 로드 실패·퇴장 중 자원 정리, 모바일 파일 크기·삼각형 예산, 실제 Three.js Meshopt 디코딩을 포함합니다. 실제 휴대폰에서 프레임 속도를 측정한 결과는 아닙니다.

로컬 미리보기에서 `?communityId=preview-ocean&hour=18`은 기존 바다와 분홍 노을, `?communityId=preview-fire-zero&hour=22`는 불이 잦아든 잉걸불을 보여줍니다. 시간 고정은 개발 서버에서만 적용됩니다. 실제 서비스의 시간은 기기 시계를 따릅니다.
