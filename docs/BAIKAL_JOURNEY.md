# 바이칼 — 세 쉼터와 오로라

- 첫 번째 온기: 중심 (-23, 6), 12개 좌석 유지. 유리벽 집에 소파와 쿠션만 단출하게 둔다.
- 눈길 쉼터: 중심 (12, -72), 낮은 천장과 창 세 개. 방 대부분이 푹신한 침대다.
- 오로라 관측소: 중심 (65, -195), 전등 없이 초만 켠 어두운 집을 이불로 채웠고 망원경이 있다. 마지막 구간이 가장 길다.
- 호수 쪽 길을 안내등으로 연결하고, 넓은 이동 통로를 얼음 장애물에서 비웠다. 남쪽 경계는 -240. 방 정원은 20명, 선택 가능한 좌석은 총 36개.

## 진행과 전망

실내 또는 현관에 순서대로 도착하면 0→1→2→3단계로 진행한다. 자유롭게 걷는 것은 제한하지 않으며, 마지막 산장을 먼저 찾아가도 이전 단계를 자동 완료하지 않는다. 진행은 이 기기의 로컬 저장소에 계정·소로우별로 저장한다. 서버 포인트/결제/아이템 권한과 무관한 개인 탐험 기록이다.

완주 후 관측소 반경 20m 안에서 보상이 완전히 드러나며 62m 밖에서는 서서히 사라진다. 개인 화면의 눈보라와 안개가 잦아들고 밤하늘과 얼음 반사에 같은 오로라가 그려진다. 공유 시간/날씨를 변경하지 않는다. 낮에는 밤 전망을 안내한다.

세 집의 닫힌 지붕·천장·충돌·눈 차폐와 서버의 좌석 좌표가 일치한다. 실내 조명은 가까운 집으로 재사용하며 모바일에서는 등 하나를 줄인다.

## 이미지

생성 원본 PNG 2개는 Git에 보관하고, 실행용 WebP 4개는 S3/CDN에서 제공한다. 모바일 이미지 두 개는 합계 282,102바이트다. 눈은 미세 입자와 부드러운 요철, 얼음은 제공된 사진의 짙은 청록색과 흰 내부 균열을 참조했다. 얼음 바닥은 방향과 위치가 다른 사진 조각을 섞어 대칭 반복과 경계선을 줄였다. 오로라는 늘린 배경 사진 대신 하늘·반사가 공유하는 동적 셰이더다.

생성 방법·정확한 프롬프트·경로: [생성 기록](../output/imagegen/baikal-assets.md). CDN 주소와 해시는 `frontend/public-assets.manifest.json`에 있다.

## 렌더링

- 후처리(`baikal-post.ts`): 다중 샘플 8비트 버퍼에 평소처럼 그린 뒤 블룸과 사진 인화식 색보정, 비네트, 그레인을 얹는다. 저사양 단계에서는 전체를 건너뛰고 바로 그린다.
- 얼음(`baikal-materials.ts`, `baikal-bake.ts`): 입사각을 따라 얼음 안을 층층이 걷는다. 캔버스로 그린 균열은 얼음 깊이로 내려가는 판처럼 보이고, 메탄 기포는 기둥 형태로 쌓인다. 산장 창은 얼음 위에 실제로 비친다.
- 실내(`baikal-cozy.ts`): 지붕이 하늘빛을 막은 대신 집마다 다른 해석적 조명, 방을 찍어 필터링한 환경 맵, 위에서 구운 접촉 그림자로 밝힌다. 그림자맵·추가 패스는 쓰지 않는다.
- 캐릭터(`rigged-avatar.ts`): 남자·여자 캐릭터는 다른 맵과 같은 원본 모델과 렌더링을 쓴다. 앉으면 좌석마다 담요가 덮인다.
- 하늘(`baikal-sky.ts`): 밤하늘과 오로라는 사실성보다 그림 같은 색을 택했다. 맑은 밤에는 옅은 오로라가 늘 있고, 여정을 마치면 전체가 열린다. 눈은 바람 없이 곧게 내린다.
- 세 집은 바닥·지붕 등 외피만 인스턴싱으로 공유하고 내부는 각각 짓는다. 충돌 범위는 집마다 다르지만 서버 좌석 좌표는 그대로다.
- 천·원목·돌·서리 텍스처는 다운로드 없이 접속 시 GPU에서 한 번 굽는다.

## 확인

- 최종 Next.js production build / TypeScript 통과.
- 바이칼 기하·이동·보상·진행·네트워크·이미지 관련 최종 검사 34개 통과.
- 서버 관련 7개 스위트 58개 통과, 네트워크 관련 60개 통과.
- 전체 공간 검사에서 코드 관련 599개 통과. 기존 CDN 파일을 읽는 7건이 샌드박스 네트워크 제한으로 실패하여 해당 6개 파일을 네트워크 권한으로 재실행했고 84개 모두 통과.
- 데스크톱/390px 모바일 브라우저: 순서 밖 방문, 1·2·3 도착, 실제 착석 UI, 진행 복원, 사진 4종 HTTP200, WebGL/GLSL/런타임 오류 0.
- 마지막 방문 후 밤 오로라와 성에가 얇은 통창, 낮 얼음 바닥의 반복 완화를 실제 캡처로 확인. 실기기 휴대폰 FPS 벤치마크는 수행하지 않음.
