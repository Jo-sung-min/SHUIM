# 온기 포인트

온기 포인트는 커뮤니티 활동으로 적립하는 내부 보상이다. 유료 불씨팝·현금·기부 금액과 분리되어 있다. 현재 구매, 사용, 양도, 현금 전환 API는 없으며 향후 꾸미기 아이템에 사용할 수 있도록 잔액과 누적 적립을 분리했다.

## 적립 규칙

- 다른 회원의 접근 가능한 외침/위로 피드에 최상위 위로 댓글을 작성하면 10P. 공백·제어 문자·보이지 않는 형식 문자를 제외한 유니코드 코드 포인트 20개 이상이어야 한다. 같은 작성자는 같은 글에서 첫 적격 댓글 한 번만 적립하며, 한국 시간 하루 최대 3회 적립한다. 답글과 자기 글에 단 댓글은 제외한다.
- 외침 작성자는 다른 회원의 보이는 최상위 댓글 하나를 채택할 수 있다. 댓글 작성자에게 50P를 지급한다. 채택 댓글의 최소 글자 수 제한은 없다. 같은 선택의 재시도는 안전하며, 삭제·숨김 이후에도 다른 댓글로 바꿀 수 없다. 위로 피드에는 채택 기능이 없다.
- 적격 위로 댓글과 위로 피드에 서로 다른 회원의 힘내요가 5/15/30개 모이면 각각 10/20/30P를 지급한다. 피드는 사진만 있어도 대상이다. 자기 반응, 비회원/샘플/제한 계정의 반응은 제외한다. 비회원 시절의 반응은 가입만으로 대상이 되지 않는다.
- 위 세 보상을 합쳐 한국 시간(Asia/Seoul) 하루 200P 한도다. 남은 한도가 적으면 그만큼만 지급한다. 한도로 지급이 0P가 된 적격 활동도 원장에 남겨 다음 날 재시도로 적립되지 않게 한다.
- 숨김·삭제·제한 계정의 콘텐츠, 서로 차단한 회원의 활동, 활성 신고 5개 이상으로 검토 중인 콘텐츠는 보상하지 않는다. 소로우 멤버 공개 범위와 예약 게시 시각도 확인한다. 이미 지급된 포인트를 콘텐츠 삭제만으로 회수하지는 않는다.
- 작성자를 숨긴 소로우 원글은 기존 열람 정책과 동일하게 원글 작성자와의 개인 차단 관계를 보상 조건으로 사용하지 않는다. 포인트 지급 여부로 익명 작성자를 추정하는 일을 막기 위한 예외이며, 공개 댓글/피드 작성자 차단은 그대로 적용한다.

## API

`GET /api/points/me`는 현재 로그인한 회원만 조회한다. 비회원은 401, 이용 제한/샘플 계정은 403이다.

```json
{
  "balance": 60,
  "totalEarned": 60,
  "todayEarned": 60,
  "dailyLimit": 200,
  "writingEarnedToday": 1,
  "writingDailyLimit": 3,
  "rules": ["한국어 규칙 안내"],
  "history": [{"id":"uuid","reason":"comfort_accepted","amount":50,"balanceAfter":60,"createdAt":1793718000000}]
}
```

`writingEarnedToday`는 지급액이 양수인 작성 보상의 **횟수**다. 내역은 최근 30개이며 금액 0인 소진 기록도 포함한다. 비공개/삭제된 원문이 유출되지 않도록 원문 ID와 링크를 응답하지 않는다. `reason`은 `comfort_write`, `comfort_accepted`, `cheers_5`, `cheers_15`, `cheers_30`이다.

`POST /api/community/comment.accept`는 `{ "postId": "...", "commentId": "..." }`를 받는다. 기존 커뮤니티 동의·계정·작성자 권한을 확인하고 최신 Store를 반환한다. 외침 Post의 선택적 `acceptedCommentId`가 채택 상태를 표시한다. 선택한 댓글이 삭제되어도 이 ID는 남아 재채택을 막는다.

CommunityStore의 User에 `registered`를 제공한다. 실제 가입 회원만 `true`이며 비회원/샘플은 `false`다. 채택 버튼은 본인과 댓글 작성자의 `registered === true` 및 기존 차단/가시성 조건을 모두 만족할 때만 표시한다.

## 일관성과 배포

V25에서 지갑, 추가 전용 원장, 채택 기록, 반응 이정표를 생성한다. 원장의 고유 이벤트 키와 지갑 행 잠금으로 재시도와 동시 적립을 직렬화한다. 커뮤니티 변경 및 적립은 같은 Spring 트랜잭션에 참여하며 실패 시 함께 롤백된다. 서버 시각으로 한국 날짜를 정하므로 클라이언트가 날짜나 금액을 지정할 수 없다.

V25는 배포 전에 이미 도달한 힘내요 이정표를 지급 없이 기록한다. 과거 활동에 일괄 소급 지급하지 않으며, 이후 새로 도달한 이정표만 적립한다. 반응을 취소하거나 다음 날 다시 눌러도 기존 이정표는 다시 지급되지 않는다. 계정 삭제 시 개인 지갑·원장은 외래 키로 삭제되며 원문 텍스트를 포인트 테이블에 보관하지 않는다.

검증은 `SOROW_TEST_DATABASE_URL=jdbc:postgresql://127.0.0.1:<port>/sorow_test`인 독립 로컬 PostgreSQL에서만 실행한다. 실제 서비스의 DB 설정이나 `.env`를 사용하지 않는다.
