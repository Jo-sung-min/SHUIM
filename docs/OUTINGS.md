# 우리의 바깥 — 모루와 함께하는 외출

홈의 방(모루/모링이 있는 그 카드) 안에서 나간다. 패드의 **나가기**를 누르고 공원·바다·산 중 하나를 고르면, 방 그림이 있던 자리에 그곳의 손그림 풍경이 깔린다. 따로 떨어진 화면도 사진도 없다 (2026-11-18 에 다시 만들었다. 그전의 `/outing` 실사 파노라마 화면은 없앴다).

## 방 안의 외출

`components/MoruOuting.tsx` (그림·움직임) · `lib/outing-room.ts` (숨은 것들의 자리와 말, 순수한 표) · `components/MoruPet.tsx` (나가기 단추·나가 있을 때의 패드).

- **풍경**: 방 그림과 같은 480×700 무대에 같은 선(짙은 갈색)·단색 면·떨리는 외곽선(`#moru-sketch`)으로 그린 SVG 한 장씩. 방의 바깥이 밤(저녁~잠)이면 밤 색으로 바뀐다. 그림 안에서는 아무것도 움직이지 않고, 움직이는 것은 친구와 말풍선뿐이다.
- **친구**: 풍경 속에 서 있다. 빈 땅을 누르면 그쪽으로 걸어가고(멀리 설수록 작다), 가만히 두면 9~14초마다 혼자 몇 걸음 걷는다. 친구를 누르면 한마디 한다.
- **숨은 것**: 장소마다 여섯 가지가 풍경 속 물건으로 그려져 있다. 이름표·자물쇠·목록이 없다. 누르면 친구가 그 옆으로 걸어가서 말해 준다.
  - 아직 열리지 않은 것: "조개가 반짝여. 조금 더 친해지면 같이 주울 수 있을 것 같아." 처럼, 날 수를 세지 않고 가까워지면 된다고만 말한다.
  - 열린 것: "조개다. 같이 주울까?" 하고 묻는다 (좋아 · 다음에).
  - 오늘 이미 한 것: "오늘은 여기서 충분히 있었어. 내일 또 오자."
- **함께하기**: "좋아"를 누르면 서버에 시작을 알리고, 서버가 정한 시간(12~20초) 동안 그 자리에서 친구가 그 활동의 말을 차례로 한다 (진행 띠 · "그만할래"). 시간이 차면 완료를 알리고, 그날 첫 활동이면 "함께 나간 n일 · 호감도 +10" 이 뜬다.
- **패드**: 나가 있는 동안에는 집으로 · 공원 · 바다 · 산 · 사람들(`/outing/meet`). 뒤로 가기도 집으로 돌아온다. 자는 중·낮잠 중에는 나갈 수 없다.
- **꽉 찬 화면**: 방은 세로에 맞춰 키워 양옆이 잘리지만, 풍경은 숨은 것들이 잘려 나가지 않게 가로에 맞춘다 (`--world-fit`).

| 장소 | 풍경 속에 숨은 것 (열리는 날) |
|---|---|
| 오후의 공원 | 벤치(0) · 낙엽 더미(0) · 돗자리(7) · 연못의 종이배(14) · 풀숲의 불빛(50) · 큰 나무(100) |
| 보랏빛 바다 | 파도(0) · 모래 그림(0) · 조개(7) · 빈 병(30) · 하늘의 별(75) · 쌓아 둔 돌(100) |
| 구름 위의 산 | 깃발과 바람(0) · 구름(0) · 보온병(14) · 이정표(30) · 능선 뒤의 해(50) · 가까운 별(75) |

이전 화면에 있던 것 가운데 지금은 없는 것: 잎·조개를 직접 고르기, 모래에 직접 그리기, 별 잇기, 나눌 것 고르기, 편지 한 줄 쓰기(추억의 메모는 비워서 보낸다), 풍경 소리, 추억 목록, 비회원 체험(방은 로그인해야 열린다). 활동은 모두 "그 자리에서 함께 있는 시간"으로 같아졌다. 서버의 규칙과 저장(아래)은 그대로다.

`/outing` 과 `/outing/space` 는 홈으로 돌려보낸다 (옛 링크·알림용).

## 100일 성장

기존 밥·방 업그레이드와 별개인 **외출 레벨**을 사용한다. 연속 출석이 아닌, 첫 활동을 완료한 서로 다른 한국 날짜 100일을 센다. 첫 활동을 마치면 하루 호감도 10·경험치 20. 반복 활동에는 추가 성장 보상이 없다. 미방문·기분·기록의 내용으로 차감하지 않는다.

| 함께한 날 | 외출 레벨 | 호감도 / 경험치 | 열리는 콘텐츠 |
|---|---|---|---|
| 0 | 1 | 0 / 0 | 세 장소, 쉬기·잎 줍기·모래 그리기·숨 고르기 |
| 7 | 2 | 70 / 140 | 피크닉, 조개 모으기 |
| 14 | 3 | 140 / 280 | 종이배, 따뜻한 차 |
| 30 | 4 | 300 / 600 | 바다 편지, 산울림 |
| 50 | 5 | 500 / 1,000 | 반딧불, 해돋이 |
| 75 | 6 | 750 / 1,500 | 두 장소의 별빛 활동 |
| 100 | 7 | 1,000 / 2,000 | 우리의 나무, 100일의 약속 |

100일 이후도 활동과 추억은 계속 이용할 수 있다. 보상·해금은 서버가 판단하고, 클라이언트가 보낸 날짜·점수는 받지 않는다. 활동 시작 토큰 및 12~20초 서버 경과 시간을 검사한다. 행 잠금과 단일 트랜잭션으로 여러 탭·기기의 같은 날 중복 보상을 막는다. 응답 유실 시 같은 완료 토큰 재시도는 보상을 반복하지 않는다. 시작 토큰은 30분 뒤 만료된다.

## 저장과 API

- `GET /api/outings`: 현재 계정의 성장·오늘의 활동·최근 추억 30장.
- `POST /api/outings/start { actionId }`: 해금 확인 후 시작 토큰과 완료 가능 시각.
- `POST /api/outings/complete { token, note? }`: 활동 완료, 그날 첫 보상, 추억 저장을 한 트랜잭션으로 처리.
- `V54__companion_outings.sql`: `outing_progress`, `outing_memories`. 계정 삭제 시 외래 키로 함께 삭제한다. 활동별 하루 한 장만 만들고, 다시 쓴 비어 있지 않은 한 줄은 갱신한다.
- 이름과 모습은 기존 계정별 모루 동행 설정을 따른다. 회원 기록은 서버에 저장하며 localStorage로 대신 성공 처리하지 않는다.
- 외출은 방 안에 있으므로 로그인한 사람만 한다. 서버에 닿지 못하면 방의 알림 줄에 그대로 알리고, 풍경은 둘러볼 수 있지만(첫날의 것만 열려 보인다) 완료 저장을 꾸며내지 않는다.

## 통합모임

`/outing/meet`는 기존 커뮤니티 약속 동의를 거친 뒤 `public` 공간의 6개 맵 인원을 조회한다. 빈 맵 우선, 모두 사용 중이면 정원이 남은 맵 중 인원이 가장 적은 곳으로 바로 연결한다. 전체 만석·조회 실패는 재시도와 모임 목록 진입을 제공한다. 진입 시 기존 서버가 정원을 다시 검사한다. 인원 조회와 입장 사이 다른 사람이 들어올 수 있어 빈 맵 독점을 보장하지는 않는다. 나갈 때 자동 연결 화면으로 돌아오는 루프를 막기 위해, 여기서 들어간 맵은 홈(방)으로 돌아온다 (`beach:return` 에 남기는 표시는 그대로 `/outing`).

## 에셋과 실행

풍경은 코드로 그린 SVG 라서 내려받는 그림이 없다. 처음 쓰던 사진 3장(`frontend/public/outing/*.webp`)과 `.gitignore` 의 예외는 지웠다.

백엔드를 배포/재시작할 때 Flyway V54 적용이 필요하다. 방 안의 외출은 백엔드를 바꾸지 않는다 (같은 `/api/outings`).

검사: `npm run typecheck`, `npm run test:outing` (규칙 `outing.test.mjs` + 방 안의 자리와 말 `outing-room.test.mjs`), `npm run build`, 백엔드 `OutingRulesTest`와 `OutingControllerTest`.

## 검증 기록 — 2026-11-17

- 외출 전용 프론트 검사 7개 통과. 모임 맵·입장 생명주기·펫 클라이언트·모루 규칙을 포함한 78개 검사 통과.
- 백엔드 외출 규칙·인증 검사 8개 통과. Gradle은 이 환경에서 배포본 다운로드 및 daemon 연결을 완료하지 못해, 설치된 JDK와 캐시 의존성으로 컴파일 후 JUnit Platform으로 실행했다.
- Next.js 운영 번들 컴파일과 TypeScript 검사는 통과했다. 전체 빌드는 정적 페이지 생성 중 Windows `EPERM mkdir`로 완료하지 못했다. 기본 출력과 별도 출력/단일 worker에서도 기존 `/auth`, `/goals` 페이지의 segment 디렉터리 생성에서 같은 종류의 오류가 발생했다. 프로젝트 설정은 검사 전 값으로 유지했다.
- 별도 모임 연속성 검사 10개 중 기존 소파 복원 검사 1개가 실패했다 (`-14.15 ≈ -14.32`). 해당 검사와 의존하는 좌석/이동 엔진 파일은 이번 변경에서 수정하지 않았다.
- 실제 브라우저 상호작용, 원격 DB 마이그레이션 및 서버 통합 검증은 아직 수행하지 않았다. 서버 배포 시 V54 적용 후 로그인한 계정의 활동 완료·재접속·날짜 전환을 확인해야 한다.
