# 바닷가 별빛 자리

모래사장의 원형 자리에서 최대 8명이 머리를 가운데로 모으고 하늘을 볼 수 있다. `하늘 보기` 또는 `같이 눕기`를 누르면 자리 가까이 걸어간 뒤 빈자리를 배정받는다. 누운 상태에서는 `하늘 보기`와 `모여 보기`로 시점을 바꾸고, `일어나기`로 걷기를 재개한다.

## 서버 배포

프런트엔드는 기존 Vercel 배포를 사용한다. 함께 눕기에는 새 서버도 필요하다.

1. AWS Elastic Beanstalk의 `sorow-api-prod` 환경을 연다.
2. **업로드 및 배포**에서 `backend/build/libs/sorow-server-2026-11-04-stargazing.jar`를 선택한다.
3. 버전 이름을 `sorow-stargazing-20261104`처럼 알아보기 쉽게 입력하고 배포한다.
4. 환경 상태가 정상으로 돌아오면 소로우 바닷가를 새로 연다.

기존 환경 변수와 포트 설정을 유지한다. 이 기능에 새 DB 테이블이나 환경 변수는 필요하지 않다. 이전 서버에서는 새 눕기 동작을 제공하지 않으며, 서버 업데이트 후 재입장하면 활성화된다.

## 확인할 동작

- 입장 소개 문구가 약 4초 뒤 사라지고 배경이 보인다.
- 밤에는 종이 질감의 풍등이 바다 위로 천천히 떠오른다.
- 별빛 자리의 빈자리로 이동한 뒤 누우면 시선이 하늘로 향한다.
- 다른 계정으로 같은 소로우에 들어가면 원형 자리에서 누운 모습이 보인다.
- 함께 눌러도 같은 자리에 겹치지 않으며, 8자리가 차면 만석 안내가 나온다.
- 일어나기·퇴장·접속 만료 시 자리가 비워진다.

## 구현 위치

- `frontend/lib/beach/stargazing.ts`: 원형 자리와 캐릭터 배치
- `frontend/lib/beach/engine.ts`: 누운 자세·하늘 및 모임 시점
- `frontend/components/beach/BeachScene.tsx`: 입장 안내·상호작용·요청 순서
- `backend/src/main/java/kr/co/shuim/beach/BeachRoom.java`: 방별 자리 배정과 동기화
- `frontend/scripts/sky-lantern-prompt.txt`: 풍등 이미지 생성 기록

자리 정보는 방문과 같은 메모리 상태이며 서버가 다시 시작하면 초기화된다.
