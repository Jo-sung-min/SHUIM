# 파라다이스 바닷가

하얀 백사장과 기존 돌절벽, 침구가 있는 오두막, 풍경 사진 촬영을 더한 버전입니다.

## 사용 방법

- 오두막 가까이에서 **이불 덮고 눕기**를 누릅니다. 오두막마다 세 자리가 있고, 빈 자리를 서버가 배정합니다. 다른 사람에게도 이불을 덮은 모습이 보입니다.
- 오두막의 **앉아서 바다 보기**로 침구 앞에 앉거나 **일어나기**로 나옵니다.
- 별빛 자리에서 누우면 모여 있는 모습을 3인칭으로 보여줍니다. **하늘 보기**를 누르면 절벽·집·캐릭터 없이 하늘만 보이고, **모여 보기**로 돌아옵니다.
- 하단 **사진** 버튼으로 풍경을 촬영합니다. 화면 버튼은 사진에 들어가지 않습니다. 미리보기에서 **사진 저장** 또는 **공유하기**를 선택합니다.
- 사진 공유를 지원하는 기기에서는 휴대폰 공유창에서 카카오톡 등 설치된 앱을 선택합니다. 지원하지 않는 환경에서는 사진을 저장한 뒤 원하는 앱에서 보내면 됩니다. 사진은 자동 업로드하거나 다른 사람에게 자동 전송하지 않습니다.

## 배포

웹 변경은 Git 푸시 후 연결된 Vercel 배포에서 반영합니다. 침구 공유 기능은 `backend/build/libs/sorow-server-2026-11-04-actions.jar`를 AWS Elastic Beanstalk의 `sorow-api-prod`에 업로드·배포하면 활성화됩니다. 기존 환경변수를 유지하며 새 DB 마이그레이션은 없습니다. 이 JAR에는 색가루, 별빛 자리, 인사 및 관리자 포옹 기능도 포함됩니다. Git 푸시만으로 AWS의 JAR가 교체되지는 않습니다.

이전 서버에서는 침구 기능을 준비 중으로 표시합니다. 서버 업데이트 후 바닷가에 다시 입장합니다. 서버를 재시작하면 잠시 머무는 자리의 점유는 초기화됩니다.

사진 공유는 카카오 SDK나 공유 전용 환경변수를 사용하지 않습니다. 로컬 설정과 Vercel 프로젝트·연결된 공유 변수 목록에 카카오 공유용 키가 없는 것을 확인했습니다. 카카오 **로그인** 설정은 별개이며 그대로 유지합니다. 사진 공유 가능 여부와 공유 앱 목록은 기기·브라우저에 따라 달라집니다. Android 앱은 기존 TWA 구조를 유지하므로 이 화면 변경을 위해 별도 Android 버전 변경은 필요하지 않습니다.

## 이미지와 확인

배경·백사장·흰 면 침구 이미지에는 내장 image_gen 도구를 사용했습니다. 원문 프롬프트와 프로젝트 자산 목록은 [paradise-assets.json](../frontend/public/beach/real/paradise-assets.json)에 기록했습니다. WebP로 인코딩한 세 이미지의 합계 용량은 약 846KB입니다.

`npm run test:beach`에서 침구 점유·해제, 카메라와 지붕·이불 사이 시야, 하늘 전용 표시, 이동 경로, 환경 조명, 촬영·저장·공유 처리를 검사합니다. 실제 카카오톡 수신자에게 사진을 전송하는 검사는 수행하지 않습니다.
