# 바닷가 행동 메뉴

바닷가 행동 메뉴와 모바일 조작 화면의 사용·배포 안내입니다.

## 화면 사용

- 하단 한 줄의 **행동** 버튼을 누르면 동작들이 위로 펼쳐집니다. 행동이 많으면 좌우로 밀어 고릅니다.
- 사람을 선택한 뒤 **인사하기**, **위로 건네기**, **안아주기**를 보냅니다. 인사와 위로는 누구나, 포옹은 관리자만 보낼 수 있습니다. 상대가 선택되지 않았으면 직접 고르는 목록이 열립니다.
- 투명 글라스 하단 줄에는 **행동·사진·시점·내 캐릭터**가 모여 있습니다. 행동 메뉴는 사용자 간 상호작용만 담습니다.
- **장작 넣기·가루 넣기**는 모닥불 중심에서 4.6m 이내로 가까이 가면 하단 줄 위에 나타납니다. 멀어져도 진행 중 요청과 재시도 정보는 유지합니다. **나가기**는 왼쪽 위에 있습니다.
- 별빛 자리나 침구 가까이 가면 별도의 **같이 눕기·이불 덮고 눕기** 버튼이 나타납니다. 누운 뒤에는 **일어나기**가 유지되며, 앉기도 가까운 좌석에서 표시됩니다.
- 하단 줄과 분리된 맨 오른쪽 **숨김**으로 화면을 정리하고, 같은 위치의 **버튼 보기**로 다시 표시합니다.

## 권한과 반영

포옹 권한은 현재 로그인 계정의 관리자 역할로 서버에서 확인합니다. 일반 사용자가 요청을 직접 만들어도 포옹을 보낼 수 없습니다. 행동을 보내는 계정과 방문 티켓의 소유자가 같아야 하며, 현재 방의 멤버 자격과 차단 규칙도 적용합니다. 거부된 포옹은 성공 연출을 보여주지 않습니다.

새 서버가 지원 여부를 알려주기 전에는 새 인사·포옹 동작을 활성화하지 않습니다. 기존 서버에 새 화면만 적용해 권한 제한이 우회되는 것을 막습니다. 서버 반영용 파일은 `backend/build/libs/sorow-server-2026-11-04-actions.jar`이며, 이전 백사장·침구·불꽃 변경을 포함합니다.

검증은 모의 계정과 로컬 미리보기로 진행합니다. 운영 중인 다른 사용자에게 행동을 보내거나 방을 생성하지 않습니다.

프런트엔드 바닷가 검사 106개와 배포용 빌드를 통과했습니다. 백엔드 검사 184개 중 154개가 통과했고, 별도 데이터베이스가 필요한 30개는 제외됐습니다. 모바일 폭 390px·320px에서 한 줄 배치, 트레이, 숨김/복원, 가까운 자리의 눕기·일어나기를 확인했습니다. 일반 계정 인사, 관리자 권한 회수 시 포옹 차단, 응답 유실 시 자동 중복 전송 방지도 기존 검증을 유지합니다.
