# 데이터 보안 작성용 증거표

작성일: 2026-10-21. **코드 검토로 확인한 후보 항목이며 제출용 확정 선언이 아닙니다.** 루체 운영자가 실제 배포 설정·위탁 계약·보유기간·로그·삭제 절차를 확인하고 Play Console 답변을 확정합니다.

## 판단 원칙

앱이 소유한 웹을 TWA로 표시한다고 데이터 보안 의무가 사라지지 않습니다. 앱의 웹·API·저장소·외부 처리업체까지 포함해 검토합니다. 기기 밖 전송은 수집에 해당할 수 있고, 메모리에 잠시 처리하더라도 콘솔의 일시 처리 기준을 확인해야 합니다. 가명 ID도 자동으로 제외되지 않습니다. 서비스 제공업체 처리나 이용자 요청에 따른 전송은 Play의 공유 예외에 해당할 수 있으나 **계약·실제 동작을 확인한 뒤** 판단합니다. [데이터 보안 공식 안내](https://support.google.com/googleplay/android-developer/answer/10787469)

## AI 전송 범위에서 주의할 부분

- 홈의 정리·칭찬·사랑 기능은 기록·메모·목표·일정 등을 서버에 보냅니다. 분석하기는 **전체 메모**를 컨텍스트로 사용할 수 있습니다.
- 흐름 정리는 선택 기간의 날짜·카테고리·점수·한 줄 기록을 전송합니다.
- 서버 AI 키가 있으면 `ClaudeClient`가 Anthropic Messages API로 텍스트를 보냅니다. API 키가 없거나 실패하면 서버에서 규칙 기반 결과를 계산합니다. **규칙 기반 결과도 기기 내 처리라는 뜻이 아닙니다.**
- AI 응답을 파싱하지 못하는 경우 오류 로그에 생성 문장 일부가 기록될 수 있는 초기 구현이 있었습니다. 릴리스에서 로그 마스킹·보관기간을 확인합니다.
- 동의 화면에는 전송받는 주체, 대상 기록, 사용 목적을 실제 구현과 맞게 표시합니다. AI 사용을 취소해도 개인 기록 기능을 사용할 수 있는지 테스트합니다.
- Anthropic 저장 지역·보유기간·학습 사용 여부·삭제 계약은 이 저장소로 확인할 수 없습니다. “학습에 절대 사용 안 함” 또는 “즉시 삭제”를 임의로 적지 않습니다.
- AI 신고 UI는 개인 기록 전체나 참고 텍스트를 자동 첨부하지 않습니다. 사용자가 신고 입력란에 직접 작성/복사한 내용만 최대 2,000자와 신고 대상 정보로 전송합니다. 신고 내용에도 민감한 기록이 들어갈 수 있으므로 신고 데이터의 접근권한·보유/삭제도 정책에 포함합니다.

작은 사진이나 GIF는 그대로 업로드될 수 있으므로 **모든 이미지의 EXIF/위치정보를 제거한다는 보장은 없습니다**. 업로드 데이터와 공개 CDN의 메타데이터를 점검합니다. 사용자 기기의 위치 권한을 요청하지 않는 것과 사진 속 위치 메타데이터는 별개입니다.

이번 작업에 추가한 계정 삭제·사용자 차단·안전 신고 기능은 서버 및 클라이언트 구현을 포함합니다. 이것이 운영 DB/파일 저장소의 삭제 완료를 입증하는 것은 아닙니다. 정책 페이지는 `LEGAL_*` 환경 설정이 확정되기 전 준비용 안내를 표시하도록 되어 있으며, 실제 파일·백업·로그·AI 제공자 처리 내용을 확인한 뒤 승인 상태로 전환합니다.

신규 업로드의 소유 관계와 삭제 재시도 큐가 추가되었습니다. 이관 전 고아 파일, S3 이전 버전, CDN 캐시 및 백업은 별도의 운영 삭제·만료 설정을 확인해야 합니다. 코드에 재시도 기능이 있다는 이유로 모든 외부 사본의 즉시 삭제를 약속하지 않습니다.
