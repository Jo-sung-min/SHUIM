# 소로우 Android 실기기 출시 시험

상태: **미실행 체크리스트**. 로컬 빌드 성공과 별개로 실제 배포 환경 및 Play에서 설치한 서명본을 검증합니다. 계정 삭제는 버려도 되는 테스트 계정으로만 수행하고 실제 이용자 데이터로 테스트하지 않습니다.

최소 2대에서 확인: 최신 Android/API 36 대응 기기, 지원 범위의 다른 Android 기기. 한국어 키보드, 큰 글꼴, 작은 화면, Wi-Fi/모바일 데이터, 최신 Chrome과 실제 기본 브라우저 구성을 포함합니다. 지원 기기 범위가 넓으면 태블릿·가로 화면도 확인합니다.

자동 검사 참고: `frontend/scripts/service-worker.test.mjs`는 개인 페이지/API를 캐시하지 않는지, `records-sync.test.mjs`는 전송 실패 후 무한 재시도 없이 미전송 기록을 보관하고 복구하는지, `service-availability.test.mjs`는 서비스 상태 판단과 장애 복구 동작을 검사합니다. 이번 로컬 검사에서는 프런트엔드 19개와 서버 47개가 통과했습니다. 390px 로컬 화면의 준비 중 표시·정책 접근·최초 AI 동의 후 반복 확인창 없음도 확인했습니다. 이는 아래의 Play 설치본·실기기·운영 환경 시험을 대체하지 않으며 아래 결과란은 미실행 상태로 유지합니다.

| A02 | 인증된 도메인의 홈·기록·나 이동 | TWA로 정상 표시, 도메인 검증 실패로 주소창이 계속 노출되지 않음 | |
| A03 | Android 뒤로가기·홈 이동·앱 재개·회전 | 예상 경로로 이동, 저장 데이터 손실·키보드 가림 없음 | |
| A04 | 인터넷 끊기→다시 켜기, 첫 실행도 별도 시험 | 오류/오프라인 상태를 알림, 재연결 시 회복, 실패를 저장 성공으로 표시하지 않음 | |

| A06 | 프런트엔드는 유지한 채 백엔드 중단→재개 | 홈·개인 기능에 기본 콘텐츠 없이 준비 중 안내만 표시. 재시도 중복 실행 방지, `/info`와 공개 정책 문서 접근 가능, 복구 후 정상 진입 | |
| B01 | 새 기기의 게스트로 기록·메모·목표 작성 후 재실행 | 작성 내용 유지, 서버 동기화 여부를 안내와 일치시킴 | |

| B03 | 게스트 기록 후 가입, A 계정 두 기기 사용 | 안내한 방식으로 기록 가져오기·동기화, 누락/중복/타인 기록 없음 | |
| B04 | 기록 수정·카테고리 순서·목표 완료·일정 저장 | 재실행/다른 기기에서 올바른 값, 네트워크 실패 이후 복구 | |
