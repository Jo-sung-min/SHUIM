# 모루 — 다마고치처럼 키우기 (방향과 상호작용 기획)

상태: 7장(꽉 찬 화면), 8장의 1·2단계, 9장(도트 게임 UI)이 적용됐다. 나머지는 기획이고 수치는 초기 조정안.

## 1. 방향: 비 오는 작은 방 × 다마고치

두 가지를 합친다.

- **비 오는 작은 방의 고요함.** 창밖에는 늘 비가 오고 빗소리가 깔린다. 방은 작고, 모루는 말수가 적다. 처음에는 "…비 온다." 정도만 말하다가
  함께한 시간이 쌓일수록 한 줄씩 속마음을 연다. 방은 느리게, 조금씩 채워진다. 우울을 고치려 들지 않고 곁에 있는 것이 전부다.
- **다마고치의 살아 있는 느낌.** 실제 시간으로 흐르는 하루, 내가 돌본 만큼 달라지는 모습, 손으로 만지는 반응.

가져오지 않을 것은 **벌**이다. 소로우는 슬픔을 나누는 곳이라, 모루가 사용자를 불안하게 하거나 죄책감을 주면 안 된다.
비 오는 방을 다루는 다른 게임에서 빌리는 것은 분위기의 뼈대(비·작은 방·천천히 열리는 마음·느린 진행)뿐이다. 캐릭터·그림·문장은 모두 모루의 것으로 새로 만든다.

| 다마고치 | 모루 |
|---|---|
| 실제 시계로 자고 깨고 배고파진다 | 그대로. 한국 시간의 하루 리듬 (기상·세 끼·잠) |
| 배고픔·행복 하트 | 배부름·온기·말끔함·기운, 숫자 대신 하트 4칸 |
| 방치하면 아프고 죽는다 | 없음. 가장 낮은 상태는 "졸림·시무룩"이고 돌아오면 바로 풀린다 |
| 삑삑 부르는 호출 | 기본 없음. 켜면 하루 한 번 조용한 소식 |
| 돌봄 품질에 따라 좋은/나쁜 캐릭터로 진화 | 좋고 나쁨 없는 분기: 내가 많이 기록한 결에 따라 모습이 달라진다 |
| 훈육 | 없음 |
| 죽음과 세대교체 | 죽음 대신 "계절 앨범": 30일마다 추억 한 장 |

## 2. 모루의 하루 (실시간)

서버는 한국 시간 08·13·19시에 식사를 정산한다. 여기에 화면 연출을 얹었다 (1단계, 시계만으로, DB 없이: `frontend/lib/moru-rules.ts`).

| 시간 | 모루 | 화면 |
|---|---|---|
| 07–08시 | 일어난다, 아침을 먹는다 | 하품, 창밖 아침빛 |
| 08–13시 | 깨어 있다 | 새싹이 창 쪽으로 기운다 |
| 13시 | 점심 | 먹는 모습, "점심 잘 먹었어" |
| 15–16시 | 낮잠 (만지면 깬다) | 이불 반쯤 덮고 졸기 |
| 19시 | 저녁 | 방 조명이 따뜻해진다 |
| 22시~ | 졸리다. 불을 꺼 주면 잔다 | 눈이 반쯤 감김, 창밖 밤 |
| 00–07시 | 잔다 (만지면 잠꼬대 한 줄, 깨우지 않는다) | 어두운 방, 숨소리 |

오래 비웠다 돌아오면 모루는 "긴 잠"에서 깨어나 반긴다. 그동안의 끼니를 빚으로 깎지 않는다 (지금 규칙 그대로).

## 3. 상태 네 가지

| 상태 | 오르는 때 | 내려가는 때 | 낮을 때의 모습 |
|---|---|---|---|
| 배부름 | 세 끼 (마음밥) — 이미 있음 | 끼니를 거를 때 | 졸려 한다 |
| 온기 | 쓰다듬기·말 걸기·함께 숨쉬기 | 하루가 지나면 절반 | 시무룩, 이불 속으로 |
| 말끔함 | 먼지 치우기·목욕 | 하루에 먼지 뭉치 1~2개 (최대 3개) | 먼지 뭉치가 굴러다님 |
| 기운 | 밤에 불을 꺼 주면 다음 날 가득 | 안 꺼 줘도 스스로 자서 절반 | 하품이 잦다 |

- 표시는 꽉 찬 화면의 하트 줄. 홈 카드에는 지금처럼 한 줄만 둔다.
- 낮다고 잃는 것은 없다. 높으면 덤이 있다: 특별한 표정과 말, 그날 성장 +1.
- 사용자의 마음 점수가 아니다. 모루의 상태일 뿐이라고 안내에 적는다.

## 4. 상호작용

모든 보상에는 하루 상한이 있다. 상한을 넘으면 반응은 그대로, 보상만 없다.

**A. 손길** — 화면만으로 가능
| 동작 | 모루의 반응 | 보상 |
|---|---|---|
| 톡 (있음) | 웃는다, "와 줘서 좋아" | 온기 |
| 길게 누르기 = 안아 주기 | 눈을 감고 기댄다, 하트 | 온기 |
| 좌우로 문지르기 = 간질이기 | 꺄르르, 새싹이 흔들린다 | 온기 |
| 새싹 톡 | 새싹이 통통 튄다 | — |
| 너무 빨리 여러 번 | 놀라서 이불 뒤로 숨었다가 빼꼼 | — |

**B. 돌봄**
| 동작 | 내용 | 보상 |
|---|---|---|
| 간식 주기 | 마음밥 1개를 직접 준다, 하루 1번 (기존 `POST /api/pet/feed`) | 온기 |
| 먼지 치우기 | 방의 먼지 뭉치를 톡 눌러 치운다 | 말끔함 |
| 목욕 | 거품을 문질러 씻긴다, 하루 1번 | 말끔함 |
| 불 끄기·켜기 | 밤에 재우고 아침에 깨운다 | 기운 |
| 이불 덮어 주기 | 낮잠·밤에 이불을 끌어 올린다 | 온기 |

**C. 놀이** — 30초 미니게임, 보상은 하루 3판까지
| 놀이 | 방법 |
|---|---|
| 빗방울 받기 | 모루를 좌우로 끌어 창밖에서 떨어지는 빗방울을 받는다 |
| 숨바꼭질 | 이불·화분·커튼 중 모루가 숨은 곳 찾기 |
| 가위바위보 | 세 판, 지면 모루가 아쉬워하고 이기면 같이 좋아한다 |
| 새싹 박자 | 새싹이 흔들리는 박자에 맞춰 톡 |

**D. 대화**
| 동작 | 내용 |
|---|---|
| 말 걸기 | 기분 칩(지쳤어·기뻐…)을 고르면 모루가 성격대로 한 줄 답한다 (문구 풀, AI 아님) |
| 모루의 쪽지 | 하루 한 장. 오늘 기록에서 고른 한 줄 ("오늘 '산책'이라고 적었네. 나도 창밖을 봤어") |
| 함께 숨쉬기 | 홈의 "숨 고르기" 1분을 모루와 함께 — 모루가 같이 부풀었다 줄어든다 |
| 이름 불러 주기 | 이름표를 누르면 모루가 돌아본다 |

**E. 꾸미기와 수집**
| 동작 | 내용 |
|---|---|
| 소품 상점 | 방문포인트로 쿠션·화분·조명·액자를 산다 (현금 결제 없음) |
| 배치 | 방의 정해진 자리 5~6곳에 놓는다 |
| 오늘의 모루 한 컷 | 방을 사진으로 저장 (기기에만) |
| 계절 앨범 | 30일마다 추억 한 장: 그달의 레벨·기록한 날·가장 많이 한 일 |

**F. 바깥**
| 동작 | 내용 |
|---|---|
| 창밖 풍경 (있음) | 실제 시간대와 맞춘다 — 밤이면 밤 풍경 |
| 소로우 공간 동행 | 바닷가·대나무숲 같은 3D 공간에 모루가 따라온다 (후순위) |
| 친구 방 구경 | 서로의 모루 방을 본다 (후순위) |

## 5. 성장

- 단계 이름: 씨앗(Lv.1–2) → 새싹(3–4) → 잎(5–7) → 꽃(8–10). 지금의 Lv.5 쿠션·담요, Lv.10 꽃을 단계의 표지로 삼는다.
- 결(분기): 최근 30일 동안 가장 많이 기록한 카테고리가 모루의 꽃 색과 작은 소품을 정한다. 마음은 보라, 몸은 초록, 관계는 분홍, 돈은 노랑, 일은 파랑. 좋고 나쁨이 없고 기록이 달라지면 따라 바뀐다.
- 성장의 중심은 여전히 기록(하루 최대 +20)과 식사(+6)다. 상호작용 경험치는 하루 +6까지.

## 6. 지키는 선

- 죽음·가출·레벨 하락·연속 출석 초기화 없음 (기존 규칙).
- 죄책감을 주는 말 금지: "왜 안 왔어"·"배고파 죽겠어" 대신 "기다렸어, 와 줘서 좋아".
- 과몰입 방지: 모든 보상에 하루 상한. 놀이는 3판 뒤 보상 없이 놀기만.
- 알림은 기본 꺼짐. 켜도 하루 한 번, 부르는 말이 아니라 소식 ("모루가 저녁을 먹었어요").
- 재화는 방문포인트와 마음밥뿐, 현금 결제는 붙이지 않는다.

## 7. 화면: 꽉 찬 화면으로 보기 (적용됨)

- 방 오른쪽 위 버튼을 누르면 방이 화면 전체를 채운다 (하단 탭바 위까지). 다시 누르거나 안드로이드 뒤로 가기로 돌아온다.
- 풍경과 모루는 카드에서의 비율 그대로 화면을 채울 만큼 커진다 (360×740 에서 1.47배). 상태 HUD와 조작 패드는 그대로 위아래에 붙는다.
- 시트(마음 기록·이사·모습)는 꽉 찬 화면 위로 뜨고, 뒤로 가기는 시트 → 꽉 찬 화면 순서로 닫는다.
- 앞으로: 꽉 찬 화면이 상호작용의 본무대다. 문지르기·미니게임·꾸미기는 여기서 하고, 홈 카드는 미리보기로 둔다.

## 8. 단계

| 단계 | 내용 | DB |
|---|---|---|
| 0 (적용됨) | 꽉 찬 화면으로 보기 | 없음 |
| 1 (적용됨) | 하루 리듬(기상·낮잠·저녁 등불·졸림·잠, 불 끄기), 손길(톡·새싹·안아 주기·간질이기·움찔), 말 걸기 문구 풀, 혼잣말, 간식 주기, 빗소리, 도트 게임 UI | 없음 (간식의 하루 한 번은 포인트 장부의 0점 표시로 지킨다) |
| 2 (적용됨) | 상태 세 가지(온기·말끔함·기운)와 먼지 치우기·목욕·서버에 남는 불 끄기, 꽉 찬 화면의 하트 줄, 모두 가득 찬 날의 반짝임 | `V42__moru_care.sql`: `user_pets` 에 열 8개 추가 (추가 전용) |
| 3 | 미니게임 2종과 하루 보상 상한, 모루의 쪽지 | 하루 보상 기록 확장 |
| 4 | 소품 상점·배치, 한 컷, 계절 앨범 | 소품 보유 테이블 |
| 5 | 성장 결 분기, 선택 알림, 3D 공간 동행 | 설정 1개 |

다음 추천은 3단계다 (미니게임 2종과 모루의 쪽지).

### 2단계에서 정한 것

- 온기·말끔함·기운은 0~4 칸이고 서버가 지킨다 (`POST /api/pet/care`, 동작: `hug`·`tickle`·`talk`·`breath`·`dust`·`bath`·`lightsOff`·`lightsOn`).
- 온기: 안아 주기·간질이기·말 걸기·간식마다 한 칸, 하루 세 칸까지. 날이 바뀌면 절반. 그냥 톡은 반응만 하고 칸은 오르지 않는다.
- 말끔함: 날이 바뀌면 한 칸씩 빠지고 그만큼 먼지 뭉치가 방에 생긴다 (많아도 셋). 먼지를 톡 누르면 한 칸, 목욕(하루 한 번)은 가득.
- 기운: 밤(22시~다음 날 7시)에 불을 꺼 주면 다음 날 가득, 아니면 절반. 자정을 넘겨 끄거나 켜면 그날 기운에 바로 반영한다.
- 하루 정산은 `care_date` 로 날짜마다 한 번만 한다. 여러 날 비워도 0 아래로 내려가지 않고, 잃는 것은 없다.
- 셋이 모두 가득 찬 날은 모루 옆에 별이 깜빡이고 한마디를 한다. 그날 한 번 성장 +1 (장부의 0점 표시 `glow:날짜`).
- 배부름은 저장하지 않고 끼니에서 읽는다: 먹었어야 할 끼니를 한 번 거를 때마다 두 칸.
- 하트 줄은 꽉 찬 화면에서만 보인다. 홈 카드는 지금처럼 패드의 한 줄만 둔다.
- 푹 잔 아침(기운 가득)에는 "푹 잤어. 어젯밤 불 꺼 줘서 고마워.", 기운이 낮은 날에는 혼잣말에 하품이 섞인다. 탓하는 말은 없다.
- 불 끄기는 이제 이 기기가 아니라 서버가 기억한다. 서버와 화면 모두 한국 시간으로 밤을 판단한다.

### 1단계에서 정한 것

- 불 끄기·켜기와 빗소리 켜 둠은 이 기기에만 기억한다. 기운 상태가 생기는 2단계에서 서버로 옮긴다.
- 간식은 `POST /api/pet/snack`: 마음밥 1개, 끼니 수는 그대로, 경험치 +1, 하루 한 번.
- 자는 모루(한밤, 또는 졸린 시간에 불을 꺼 준 뒤)는 만져도 깨지 않고 잠꼬대만 한다. 낮잠(15시)은 만지면 깬다.
- 혼잣말은 45~75초에 한 번, 깨어 있고 아무 일도 없을 때만. 레벨 1·3·5에서 한 묶음씩 열린다 (2단계에서 "마음의 거리"로 바꾼다).
- 빗소리는 녹음 파일 없이 Web Audio 로 만든다. 브라우저 정책상 방을 한 번 만진 뒤에 켜진다.
- 개발 확인용: `?moruHour=22` 로 시간대 고정, `?moruQuick=1` 로 혼잣말 간격 3.5초 (운영 빌드에서는 무시).

## 9. 화면: 도트 게임 UI (적용됨)

모루의 방 안에 있는 UI는 앱의 유리 UI가 아니라 **그림과 같은 세계의 도트 게임 UI**다. 방 밖(홈의 다른 카드, 탭바, 시트)은 앱 UI 그대로 둔다.

| 원칙 | 내용 |
|---|---|
| 선과 모서리 | 2px 진한 외곽선, 모서리는 한 칸 빠진 계단. 둥근 모서리·흐림·그라데이션·부드러운 그림자 없음 |
| 면 | 단색. 위쪽 1줄 밝은 선, 아래쪽 턱(3~4px)으로 두께를 낸다. 누르면 턱이 눌려 2px 내려간다 |
| 색 | 방 그림에서 가져온 고정 색: 먹보라 외곽선 `#2b2233`, 크림라일락 판 `#f3eaf4`, 보라 강조 `#7a5fa8`, 포인트 금색 `#96661a`. 낮·밤 테마와 무관 (방은 늘 같은 세계) |
| 글자 | 한글 도트 글꼴 Galmuri11 (SIL OFL 1.1). 11~13px, 굵기는 400·700 두 가지 |
